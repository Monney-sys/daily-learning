## 沉淀规则(怎么长新内容)

- **触发**:每次打靶/做题/应急中踩了坑、或 Hermes 帮你跑通了某条命令 → 顺手记进来(由 Hermes 代写,你不用自己动手)
- **只记验证过的**:网上抄的、没跑过的命令不往里放(避免变成吃灰 cheatsheet)
- **格式**:`**用途**: <命令> — 备注/踩坑`,一条一列表项,分组按手法/工具
- **来源**:命令从旧笔记抽出时带 `(源:日期-主题)` 标注,方便回查原笔记上下文

## 每条命令的格式约定

```markdown
### 分组名(按手法/工具)
- **一句话用途(中文)**: `可直接复制的命令` — 备注/踩坑点(何时用、参数坑)
```
