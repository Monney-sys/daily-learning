# 文件包含漏洞 ## 脚本 / 语言 - PHP（主力） - JSP / ASPX - Python / JavaWeb - 现代框架形态 - Node.js 模板包含 - Go http.Dir - Spring 资源读取 - Thymeleaf / FreeMarker - Nginx alias 穿越 ## 检测 - 白盒 - 代码审计 - SAST 工具（Semgrep / CodeQL） - AI 辅助审计（LLM 污点链） - 黑盒 - 公开漏洞 - 手工看参数值及功能点 - 模糊测试（ffuf / wfuzz） - 灰盒 / IAST - 运行时污点追踪 - 差分响应检测 - 供应链维度 - SCA 组件扫描 - 已知 CVE 匹配 ## 类型 - 本地包含 LFI - 无限制 - 有限制（后缀 / 前缀） - 远程包含 RFI - 无限制 - 有限制（allow\_url\_include） - PHP 伪协议 - php://filter（任意读 + filter 链 RCE） - data:// - zip:// - phar://（触发反序列化） - file:// / http:// / ftp:// - 特殊路径包含 - /proc/self/environ - /proc/self/fd/N - session 文件 - 日志文件 - 临时上传文件 ## 利用 - 经典组合拳 - LFI → 源码泄露 → 二次审计 RCE - LFI + 日志投毒 → RCE - LFI + Phar 反序列化 - LFI + 文件上传（图片马 / zip） - LFI + PHP filter 链 → 无文件 RCE - 横向扩展 - LFI → SSRF → 云元数据 169.254.169.254 - K8s secrets / 容器环境变量 - 读取 .env / 配置文件 → 凭据泄露 - 读取 SSH 私钥 / .git - AI 时代利用 - LLM 自动生成 payload / filter 链 - 自动化漏洞链编排 ## 修复 - 开发层 - 固定后缀、白名单 - 路径规范化（realpath / basename） - allow\_url\_include=Off - 限制 php:// 协议 - 运行时 - WAF / RASP - 容器/沙箱隔离 - 最小权限降权 - 敏感目录禁止包含 - 管理面 - SCA / SAST 接入 CI/CD - 组件版本治理 - IMDSv2 云元数据防护 - 密钥轮换 - 监控 - 异常参数检测 - 日志投毒痕迹审计 - 蜜罐诱捕
